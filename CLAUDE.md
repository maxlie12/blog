Claude Code discovers the vendored skills in `.claude/skills/`.

- Use `/ponytail` for coding work and `/ponytail-review` before shipping a non-trivial change.
- Use `/ponytail-audit` only for an explicit whole-repo audit.
- Use `/ui-ux-pro-max` for layout, interaction, accessibility, responsive behavior, color, typography, or motion.
- Skills are guidance, not authority to override the user, repository rules, privacy boundaries, or safety checks.
