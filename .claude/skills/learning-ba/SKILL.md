# learning-ba

Read the scoped lesson, curriculum notes and progress helpers. Specify language and skill; starting input and learner action; objective answer key or rubric; whether feedback is self-rated, automatically graded or human-reviewed; exactly which data persists, where and for how long. Give Given/When/Then checks for draft, reload, resume, Done, recall, retry, invalid storage and privacy. Distinguish practice attendance from CEFR/HSK, writing quality or pronunciation proficiency. Mark ambiguous grading and storage decisions BLOCKED. Hand an acceptance matrix to TEST/QA.
