# Level lesson library

The Learning picker filters language, task level, skill, search text and server review status. English task levels are derived from the CEFR-style practice label when present, otherwise the first label (e.g. B1+ practice / B2 source and B2 material / B1+ practice both belong to B1+). Chinese uses Beginner and Elementary as internal teaching groups, not certified HSK/CEFR levels. Japanese uses Starter, A1 and N5 labels without treating them as equivalent assessments. Switching language clears the selected level. Counts reflect the selected language and task level; local drafts do not affect reviewed progress.

The library includes four English skills at A2, B1, B2 and C1, four Chinese skills in each of two beginner groups, and a four-skill Japanese Starter set. Existing B1+ daily practice is preserved. English listening/reading links use free British Council audio and transcripts. Chinese audio uses accessible native recordings in HelloChinese, whose free content is limited and whose Premium is paid. Japanese Starter listening/speaking links to Japan Foundation Irodori audio and uses original micro-tasks aligned to Can-do goals. No source transcript or answer key is copied.

Library tasks are typed definitions in src/lib/levelLessons.ts, merged with stored and daily lessons. A stored lesson keeps precedence. Authenticated submission materializes a missing library definition without overwriting Studio edits. Read-only preview continues using local PracticeCoach drafts; no server writes or CEFR upgrades are inferred. Selecting a higher-level task is optional exploration, not an assessment result.
