# Guided practice

`/learning/session` provides a single-task flow: setup → input → comprehension → speaking then writing → self-check → targeted repair → summary.

English keeps the free British Council B2 Digital Detox lesson for the current seven-stage flow. Stage 1 opens the official source page for audio and transcript instead of hotlinking an MP3 that may expire. Cambridge English “Listening to dialogues” is shown as an optional B1–B2 activity for the next three-day cycle, not mixed into the current Digital Detox answers.

Chinese is optional Beginner. It opens Mandarin Bean in the browser for a graded dialogue, pinyin controls and audio recorded by Chinese teachers; no app install or account is required for the free lesson. Full translations or worksheets can require Premium. An original synthetic-speech fallback is labelled as device-generated rather than native audio.

Drafts save locally on each edit. `guided-practice-history-v1:<language>` retains sessions by their original `startedAt`, while the old latest-draft key is retained for compatibility and migrated without deletion. Starting a session never prunes earlier sessions automatically. The setup screen lists saved sessions and lets the learner reopen and edit one; its completion ID stays unchanged, so editing does not duplicate Done/streak. Storage failures are shown explicitly rather than claiming a save succeeded. Browser storage is finite, device-specific and can be cleared by the browser; this is not a cloud backup. Already-overwritten drafts cannot be reconstructed. Nothing is uploaded to the public repo or database. Completion records practice on this device; it does not infer a CEFR score or reviewed result. Audio recordings are not stored by this screen.

Self-check is a rubric revealed after a comprehension response and an output response. It is not personalised AI feedback. Learners can copy their work to ChatGPT and paste received feedback back into the optional field. Repair follows the learner-selected gap. Planned 5/10 minute budgets are guidance; actual minutes are self-reported.
