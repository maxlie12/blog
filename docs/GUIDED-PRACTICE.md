# Guided practice

/learning/session provides a single-task flow: setup → input → comprehension → speaking then writing → self-check → targeted repair → summary. English defaults to self-reported B1+ with the free British Council B2 Digital detox audio, hotlinked with source attribution and no copied transcript. Chinese is optional Beginner, linking accessible native-speaker HelloChinese content; an original synthetic speech fallback is labelled as device-generated rather than native audio.

Drafts save locally on each edit, keyed by language and version. Resume is explicit; pause does not remove a draft. Starting new replaces the most recent draft of that language. Nothing is uploaded to the public repo or database. No CEFR score, reviewed count or streak is generated. Audio recordings are not stored by this screen.

Self-check is a rubric revealed after a comprehension response and an output response. It is not personalised AI feedback. Learners can copy their work to ChatGPT and paste received feedback back into the optional field. Repair follows the learner-selected gap. Planned 5/10 minute budgets are guidance; actual minutes are self-reported. Next-day review is a displayed suggestion, not a new automation. Future storage/AI integration requires server-side credentials and deliberate configuration.
