# LANG-001 · Web practice sources and Stage 1 audio

## Goal
Make the first guided-practice stage usable on mobile without an app-only dependency or a broken hotlinked audio player.

## Scope
- Keep the existing British Council Digital Detox source for the current seven-stage English flow.
- Open official audio/transcript on the source page instead of hotlinking an MP3.
- Add one official Cambridge B1–B2 listening activity for the next three-day cycle.
- Replace HelloChinese app references with Mandarin Bean web dialogues, native-teacher audio and pinyin.
- Keep Chinese active output inside Learning: recall, speaking and typing; handwriting remains optional.

## Non-goals
- Do not rotate to a new English source every day; one source remains active through listen → shadow → retell.
- Do not redesign the Learning information architecture or streak.
- Do not claim external exercise results or CEFR progress.

## Acceptance checks
- Stage 1 has a clear, keyboard-accessible source button and no empty audio player.
- Chinese beginner and elementary listening/speaking/writing tasks link to a free web lesson.
- Source labels show Mandarin Bean.
- Production build succeeds and the Learning page renders.
