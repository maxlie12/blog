# Practice coach

Daily packets are displayed English listening → reading → speaking → writing → optional application task, then Chinese. The order does not imply reviewed progress; a busy learner may start a single 5-minute task.

Every lesson offers methods suitable for its skill: recall, shadowing, retelling, changing the situation or a short Learning Note. Each method shows one action and one expected output. In anonymous preview, a saved nonempty response is enough to enable Done; the general self-check, one-point repair and ChatGPT export are optional disclosures rather than gates. Signed-in learners see the same method choices before submitting their private attempt for review. Method choice guides the session but does not itself count as evidence. This is not automated scoring, personalised diagnosis, or a CEFR assessment. Preview responses are not sent to the public repo or database. Storage is versioned localStorage per lesson; old version-1 drafts remain readable and restore is explicit. Browser/device changes or clearing storage can remove drafts. Audio is not stored by this form.

Learners report actual minutes, support used and focus. ChatGPT feedback can then distinguish comprehension, reasoning, language and delivery from submitted evidence. A local draft never adds a reviewed count or a streak. Suggested retrieval after 1, 3 and 7 days is a starting schedule, not a universally optimal interval. Daily learning continues at the current self-reported level until real work is available.
