# Practice coach

Daily packets are displayed English listening → reading → speaking → writing → optional application task, then Chinese. The order does not imply reviewed progress; a busy learner may start a single 5-minute task.

Anonymous preview lessons have a device-local practice form. A nonempty response unlocks a general self-check rubric, an optional drill based on the learner's own selected gap, a revision field, and export text for ChatGPT review. This is not automated scoring, personalised diagnosis, or a CEFR assessment. No responses are sent to the public repo or database. Storage is versioned localStorage per lesson; restore is explicit. Browser/device changes or clearing storage can remove drafts. Audio is not stored by this form.

Learners report actual minutes, support used and focus. ChatGPT feedback can then distinguish comprehension, reasoning, language and delivery from submitted evidence. A local draft never adds a reviewed count or a streak. Suggested retrieval after 1, 3 and 7 days is a starting schedule, not a universally optimal interval. Daily learning continues at the current self-reported level until real work is available.
